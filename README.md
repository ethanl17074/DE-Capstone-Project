In my project, I learned the skills necessary to use and enable a Pitop to run code while integrating different sensors and outputs. 
Learning how to use a piTop was difficult at first, but eventually I learned how to utilize different sensors such as ultrasonic, 
potentiometers and buttons to create useful code that a Pitop could run. For my project specifically, the main components I used were LED's, 
buttons, and the Pitop itself. By using the buttons and manipulating which LED was on, I could create different outputs that would affect the 
score of my counters. Mastering the buttons and LED's were important as it allowed the game to have three different states, and an input that would
change its output depending on the states of the LED's.

Through this project, besides learning how to work with different sensors, I was also further exposed to python code and the different intricacies that
come with it different from Java, which is what I have spent all year learning in AP CSA. Despite knowing how to use for loops and if/else statements in Java already, I had to modify and adapt to another coding language when dealing with this project. Variable naming and creation as well as different syntax were also
important takeaways from my project. When I ran into the problem of having to generate a random light every second while simultaneously running the main game loop, I learned the importance of using threads, in order to smoothly handle two while loops at the same time.
